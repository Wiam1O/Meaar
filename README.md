Meaar Academic System

Meaar is a web-based academic assessment system that analyzes exam results, measures Course Learning Outcomes (CLOs) achievement, and generates academic reports and dashboards.

Key Features:
- Exam results analysis.
- CLO achievement assessment.
- Automated PDF reports.
- Dashboards and data visualization.
 Role-based access management.

Technologies:
C#, ASP.NET Core MVC, SQL Server, HTML, CSS, JavaScript, EPPlus, Notativa, and ZipGrade.
